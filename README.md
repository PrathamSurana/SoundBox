# SoundBox 🔊

A simple and fun soundbox application built with HTML, CSS, and JavaScript. Click on the buttons to play different sounds!

## Features

- A clean and simple user interface.
- A collection of pre-loaded sounds.
- Easy to add or change sounds.
- Responsive design that works on different screen sizes.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You just need a modern web browser like Chrome, Firefox, or Safari.

### Installation

1.  Clone the repo (if you are using Git):
    ```sh
    git clone https://github.com/your-username/SoundBox.git
    ```
2.  Navigate to the project directory and open `index.html` in your browser.

## How to Use

   *   **Mouse**: Click on any of the sound pads to play the sound.
*   **Keyboard**: Use the keys on the `QWER`, `ASDF`, and `ZXCV` rows of your keyboard to trigger the sounds.
*   **Stop**: Click the "STOP ALL" button or press the `Spacebar` to stop all currently playing sounds.

## Technologies Used

*   **HTML5**: For the structure of the web page.
*   **CSS3**: For responsive layout (CSS Grid) and modern styling.
*   **JavaScript**: For handling the logic of playing and stopping sounds.
